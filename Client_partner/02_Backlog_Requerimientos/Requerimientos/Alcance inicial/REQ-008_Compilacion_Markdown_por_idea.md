## Qué se necesita
Generar un artefacto Markdown canónico por idea consolidada, consultable desde el portal y regenerable desde los datos operativos.

## Alcance
- Incluye: plantilla, persistencia, regeneración, una sola fila por idea en Resultados, con umbral/origen y la nota "X de Y puntos".
- No incluye: versionado en Git del Markdown (post-MVP).

## Criterios de aceptación
- [x] Genera el Markdown por idea y permite consultarlo.
- [x] Permite regenerarlo desde los datos operativos.
- [x] Cada Markdown expone umbral, origen y calificación de la versión exacta.
